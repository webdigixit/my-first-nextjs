# My First Next.js Project 🚀

A modern, responsive web application built with **Next.js 15**, **React**, and **Tailwind CSS**. This project fetches data from an external API and displays it in a clean, user-friendly interface.

## 🌟 Features
- **Server-side Data Fetching**: Retrieves user data from JSONPlaceholder API.
- **Responsive Design**: Mobile-first UI using Tailwind CSS Grid.
- **Modern Navigation**: Fast, client-side routing with Next.js `Link` component.
- **Interactive UI**: Hover effects and polished card layouts.

## 🛠️ Tech Stack
- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Deployment**: [Vercel](https://vercel.com/)
